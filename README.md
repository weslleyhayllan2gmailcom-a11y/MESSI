# Site Completo sobre CLT - Consolidação das Leis do Trabalho

## 📖 Descrição

Site informativo e educacional sobre a **Consolidação das Leis do Trabalho (CLT)** do Brasil. Contém informações completas sobre direitos do trabalhador, deveres, história, jornada de trabalho, benefícios e muito mais.

## ✨ Características

✅ **Design Responsivo** - Funciona em desktop, tablet e celular  
✅ **Interface Moderna** - Visual atrativo com gradientes e animações  
✅ **Conteúdo Completo** - Todos os direitos e deveres do trabalhador  
✅ **Navegação Intuitiva** - Menu fixo e links de âncora  
✅ **Accordion Interativo** - Seções retráteis de temas importantes  
✅ **Performance** - Carregamento rápido e otimizado  
✅ **Acessibilidade** - Semanticamente correto e amigável

## 🚀 Como Usar

### Opção 1: Abrir no navegador
1. Baixe os arquivos
2. Abra `index.html` com seu navegador preferido
3. Navegue pelas seções usando o menu

### Opção 2: Servir com servidor local
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (http-server)
http-server
```
Então acesse: `http://localhost:8000`
